# multilingual-transcription

## Setup

Run:

```bash
uv sync
```

Create `.env` file in the root folder of this repository, with following fields:
```.env
OPENAI_API_KEY=<your-openai-key>
HUGGINGFACE_TOKEN=<your-huggingface-key>
```

A tiny amount of tokens are ued from openai platform, so total costs should not exceed a few cents.
